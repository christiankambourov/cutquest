Goals
Apple Health
Set up the iOS Shortcut
  1. Open Shortcuts → + → name it Cut Quest Sync.
  2. Add Find Health Samples: Type Weight, Start Date is today, Sort Latest First, Limit 1. Then Get Details of Health Sample → Value. Long-press the result → Rename to weight.
  3. Add Find Health Samples: Steps, Start Date is today → Calculate Statistics → Sum. Rename steps.
  4. Same for Active Energy (Sum) → active_kcal.
  5. Resting Heart Rate, today, latest, limit 1 → Value → resting_hr.
  6. Sleep Analysis, Start Date in the last 1 day, Value is Asleep (or Core/Deep/REM) → Get Details Duration → Calculate Statistics Sum → Calculate ÷ 3600 → sleep_hours.
  7. Find Workouts: Start Date is today, Type Running, limit 5. Add Repeat with Each; inside, add a Dictionary with keys kind=Type, miles=Distance (in mi), minutes=Duration (in min), kcal=Active Energy, start=Start Date (format ISO 8601). After the loop the result is the list → rename workouts.
  8. Add Dictionary with keys weight, steps, active_kcal, resting_hr, sleep_hours (Number) and workouts (Array) set to the variables above.
  9. Add Get Contents of URL: URL (your ingest URL), Method POST, Headers Authorization = Bearer YOUR_TOKEN, Request Body JSON → File = the Dictionary.
  10. Optional: Show Notification with the result. Run it once and allow Health access for every type.
  11. Automation: Automation tab → + → Time of Day → 9:00 PM, Daily → Run Immediately (turn off "Notify When Run") → choose Cut Quest Sync. Add a second 7:30 AM automation so morning weigh-ins sync too.
